# 📈 股票技术分析（Rust + Vue3）

一款本地运行的 A 股技术分析应用：**多账号数据隔离 + 多因子技术指标评分预测走势 + 结合持仓成本给出具体可执行的操作建议**（止损价、止盈/减仓位、补仓测算、费用核算）。

> ⚠️ 免责声明：本项目所有评分、预测与建议均由技术指标规则自动生成，仅供学习与研究参考，**不构成任何投资建议**。股市有风险，投资需谨慎。

## 账号系统

- 用户名 + 密码注册/登录（**PBKDF2-HMAC-SHA256 十万次迭代**，90 天签名 token）
- **数据按用户隔离**：持仓/流水/观察列表存于 `data/users/<用户名>/`，互不可见
- 行情/财报缓存（公共数据）全局共享
- 首次使用在登录页「注册一个」创建账号；存量数据已迁移至 `yihai` 账号
- **登录限流**：同一 IP 10 分钟内失败 5 次锁定 10 分钟（注册邀请码错误同样计数）

### 安全配置（公网暴露前必读）

| 配置 | 位置 | 作用 |
|---|---|---|
| `REGISTER_INVITE=<邀请码>` | `backend/.env` | 关闭开放注册：新用户注册必须携带邀请码（未设置 = 开放注册） |
| `STOCK_APP_SECRET=<随机串>` | 环境变量 | token 签名密钥；未设置时首次运行自动生成 `data/app_secret`（0600 权限） |

- 密码与 token 在公网明文传输，**强烈建议**用 Caddy 套 HTTPS：仓库根目录 `Caddyfile.example`，装好域名解析与 443 放行后 `caddy run --config Caddyfile.example` 即可（自动申请/续期证书）
- 只需暴露 8787（HTTP）或 443（HTTPS）一个端口；5173 为开发服务器，不要暴露
- 公网访问方案（IPv6 直连 / 运营商公网 IP + DDNS / 内网穿透）见上方「让家里 Mac 在外可访问」的需求记录

## 功能特性

### 个股分析
- **K 线图**：前复权日 K + MA5/10/20/60 + 成交量 + MACD，可切换 RSI / KDJ 副图，支持缩放平移
- **关键价位标注**：支撑位（绿）、压力位（橙）、持仓成本（黄）、止损位（红）直接画在图上
- **多因子评分**（-100 ~ +100 → 强烈看空 / 看空 / 震荡 / 看多 / 强烈看多）：

  | 因子 | 权重 | 内容 |
  |---|---|---|
  | 趋势 | 25% | 均线多空排列、价格与 MA20/60 关系、高低点结构 |
  | 动量 | 20% | MACD 金叉死叉、零轴位置、柱体伸缩 |
  | 超买超卖 | 15% | RSI 区间与顶底背离、KDJ 交叉 |
  | 量价 | 15% | 放量上涨/缩量回调为正、放量下跌为负 |
  | 布林波动 | 10% | 布林带位置、带宽收张（变盘窗口提示） |
  | K线形态 | 15% | 长下影、吞没、连阳连阴、跳空缺口 |

- **基本面参考**（估值 + 财报两级）：
  - 估值快照（腾讯行情）：市盈率 TTM / 市净率 / 总市值，调整规则：亏损 -15、PE>100 -10、PE<15 +8、破净 +5、PB>8 -5
  - 财报因子（东财 F10 最新报告期，按日缓存）：营收增速、归母净利增速、ROE、毛利率。
    营收/净利增速 ≥20% 各 +6、10~20% 各 +3、负增长 -8、营收 <-20% 或净利 <-30% 各 -12；
    ROE ≥15% +6、10~15% +3、<5% -5、为负 -8；毛利率 ≥40% +3、<15% -2
  - 基本面合计加分封顶 +15、扣分封底 -30，以「技术面 X + 基本面调整 Y = 综合 Z」透明呈现
  - 交易快照与组合评分使用同一口径，保证复盘一致性

- **走势预测**：支撑/压力位聚合识别（近期高低点、均线、布林轨道）+ 基于 ATR 波动率与评分方向的未来 5/10/20 日目标区间，并给出置信度
- **操作建议**（核心）：结合持仓状态与风险偏好

- **当日盘面分析**：个股分析页底部自动生成当日盘面复盘——盘面定性（多头强度仪表）、
  多空要点对照、K线形态与量能解读（含量比）、关键位攻防结果（20日线/60日线/
  近20日高低点/布林轨道：守住/跌破/突破/承压/未触及），以及**次日四情景预案**
  （强势延续 / 中性震荡 / 回踩支撑 / 突破压力，区分持仓者与未持仓者口径）
- **AI 分析建议**：将系统算好的评分/因子/基本面/盘面/关键位打包发给大模型
  （OpenAI 兼容接口），生成文字解读与操作建议。配置 `backend/.env`
  （见 `.env.example`：`AI_API_KEY` 必填，`AI_BASE_URL`/`AI_MODEL` 可选，
  支持 DeepSeek/Moonshot/智谱/Ollama 等）；同一数据当日缓存不重复消耗 token；
  未配置时功能优雅降级并显示配置指引
- **AI 调用透明化**：每次调用把「完整提示词 + 模型回复」记录到 `data/ai_log.jsonl`，
  前端面板点「查看发送给 AI 的完整提示词」即可核对 AI 收到的全部数据——所见即所得，
  防止黑箱编造

### 持仓管理
- 录入持仓（代码、成本价、股数），本地 JSON 持久化
- **模拟交易**：在分析页建议面板或持仓页点击「买入 / 卖出」下单记账（按建议价位预填或自定义价格）
  - **A 股费用模型**：佣金万 2.5（最低 5 元，双边）+ 印花税万 5（仅卖出）+ 过户费万 0.1（双边）
  - 买入费用**计入持仓成本**（加权摊薄）；卖出盈亏为**扣费后净额**，并按**券商摊薄口径**回冲剩余持仓成本（卖出盈利摊低成本、亏损抬高成本）；费率在 `backend/src/config.rs` 调整（前端交易弹窗的费率常量需同步）
  - 买入自动加权摊薄成本；卖出清仓自动移除持仓；超量卖出会被拒绝；交易弹窗实时预览成交后的成本/股数/费用/盈亏
- **历史交易复盘**：持仓页「历史交易复盘」面板
  - 统计卡：总笔数、卖出胜率、已实现盈亏、最佳/最差一笔
  - 每笔交易记录下单时点的技术面快照（评分/评级/系统建议），并自动标注「跟随建议 / 逆建议 / 中性」
  - 个股分析页的 K 线图自动标注该股历史买卖点（B/S 三角标记，悬浮显示成交明细）
- 组合总览：总市值、浮动盈亏、收益率、已实现盈亏、个股权重
- 每只持仓自动生成：趋势评级 + 操作结论 + 具体止损位
- 建议矩阵：**盈亏状态（浮盈 / 成本附近 / 浅套 / 深套）× 趋势评级（看多 / 震荡 / 看空）**，例如：
  - 浮盈 + 看多 → 持有，跟随均线移动止盈
  - 浅套 + 看空 → 逢反弹减仓，破位止损不硬扛
  - 深套 + 看空 → 分批止损离场
  - 成本附近 + 看多 → 持股待涨，回踩支撑可补仓（附补仓后新成本测算）

### 观察列表
- 自行添加感兴趣的股票（搜索选中即加入），本地 JSON 持久化、按用户隔离
- 添加时自动记录**基准价**（最近收盘价，盘中添加则为当时最新价）与添加时间
- 列表实时展示：最新价、今日涨跌、**自添加以来累计涨跌**（金额 + 百分比）及添加后每日收盘迷你走势线
- 自添加涨跌按前复权口径计算，除权除息不会产生假涨跌；单用户上限 50 只

### 风险偏好
全局切换 **保守 / 稳健 / 激进**，影响止损线（5% / 8% / 12%）、移动止盈均线（MA10 / MA20 / MA60）、建仓与补仓比例。

## 快速开始

依赖：Rust（cargo）、Node.js ≥ 18。

```bash
./start.sh
# 打开 http://127.0.0.1:5173
```

或分步手动启动：

```bash
# 后端 (0.0.0.0:8787，局域网可访问)
cd backend && cargo run

# 前端 (127.0.0.1:5173)
cd frontend && npm install && npm run dev
```

生产模式：`cd frontend && npm run build` 后，后端会直接托管 `frontend/dist`，只启动后端即可访问 `http://127.0.0.1:8787`。

### 开机自启（macOS LaunchAgent）

已配置后端 release 版随登录自启（`~/Library/LaunchAgents/com.deng.stock-analysis.plist`，
模板见 `backend/com.deng.stock-analysis.plist`），启动的是 `backend/target/release/stock-analysis`
（工作目录为 `backend/`，保证 `data/` 与 `../frontend/dist` 正确解析），崩溃后自动拉起，日志写 `backend/data/server.log`。

```bash
# 停止/移除自启
launchctl bootout gui/$(id -u)/com.deng.stock-analysis
# 重新加载
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.deng.stock-analysis.plist
```

> 若以后改动源码，先重新构建（`cd backend && cargo build --release` 与 `cd frontend && npm run build`），
> 再 `launchctl kickstart -k gui/$(id -u)/com.deng.stock-analysis` 重启服务即可。

### 手机访问

- **同一 WiFi**：手机浏览器直接访问 `http://<Mac的局域网IP>:8787`（如 `http://192.168.31.48:8787`，IP 用 `ipconfig getifaddr en0` 查看）
- **出门在外**：推荐 Tailscale 组网——Mac 与手机装 Tailscale 并登录同一账号，手机访问 Mac 的 Tailscale IP（100.x.x.x）的 8787 端口；数据不出家门、不暴露公网。若改用 frp/Cloudflare Tunnel 等公网方案，**务必先为服务增加访问鉴权**（当前系统无密码）。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/register` | 注册 `{username, password}` → 返回 token |
| POST | `/api/auth/login` | 登录 `{username, password}` → 返回 token |
| GET | `/api/auth/me` | 校验 token（Header: `Authorization: Bearer <token>`） |
| GET | `/api/search?q=` | 股票搜索（代码/中文名/拼音缩写，无需登录） |
| GET | `/api/analysis/{code}?risk=` | 全量分析（登录后带该用户持仓上下文） |
| GET | `/api/session/{code}` | 当日盘面分析 |
| GET/POST | `/api/positions` | 持仓列表 / 新增（需登录，按用户隔离） |
| PUT/DELETE | `/api/positions/{id}` | 修改 / 删除持仓 |
| GET/POST | `/api/trades` | 交易流水 / 模拟下单（需登录，按用户隔离） |
| GET | `/api/portfolio?risk=` | 组合汇总与逐只建议（需登录，按用户隔离） |
| GET/POST | `/api/watchlist` | 观察列表 / 添加并记录基准价（需登录，按用户隔离） |
| DELETE | `/api/watchlist/{code}` | 移除观察标的 |

`risk` 取值：`conservative` / `balanced` / `aggressive`。

## 技术栈与架构

```
backend/   Rust (axum + tokio + reqwest)
  ├── users.rs         账号与认证（PBKDF2 密码哈希 + 90天 token）
  ├── data_source.rs   腾讯行情（主源）+ 东方财富（备源）+ 分级缓存
  ├── indicators.rs    MA/EMA/MACD/RSI/KDJ/BOLL/ATR（含单元测试）
  ├── scoring.rs       六因子评分引擎 + 基本面调整
  ├── forecast.rs      支撑/压力位 + ATR 目标区间
  ├── session.rs       当日盘面分析 + 次日预案
  ├── advisor.rs       持仓成本 × 趋势评级 → 操作建议矩阵
  ├── positions.rs     持仓 JSON 持久化（按用户隔离，含费用摊薄）
  └── trades.rs        模拟交易流水 JSON 持久化（按用户隔离）
frontend/  Vue 3 + Vite + ECharts（含登录页，移动端适配）
  ├── views/AnalysisView.vue   分析页（K线+评分+预测+建议+盘面+快捷交易）
  └── views/PortfolioView.vue  持仓页（录入+组合总览+买卖+历史交易复盘）
data/
  ├── users.json            账号表
  ├── users/<name>/         各用户私有数据（positions.json / trades.json）
  └── kline_*.json, f10_*   公共行情/财报缓存
```

- 数据源：腾讯 `fqkline` 前复权日线（主）、东财 `push2his`（备）、东财 searchapi（搜索）；
  **K线缓存时效**：盘中（交易日 09:15~15:35）仅保留 10 分钟（保证盘中评分尽量新鲜），
  收盘后/周末/节假日当日缓存全天有效（收盘数据不再变化），跨交易日自动失效
- 指标与建议全部为本地规则计算，透明可解释（每个因子都给出文字理由）
- 运行测试：`cd backend && cargo test`（18 个单测，含涨/跌行情端到端评分合理性、
  费用记账、缓存时效等校验）

## 常见问题

- **搜索不到股票**：目前仅支持沪深京 A 股（type=14）
- **数据不准/停牌**：长期停牌股可能K线为空，接口会返回明确错误提示
- **调参**：因子权重与阈值在 `backend/src/config.rs`，改后 `cargo run` 重启即可
